# Customer guides

Short, printable how-tos written for the people at a dealership, not for engineers.
One file per device family, because the menus differ and a single guide with three
branches is a guide nobody finishes.

| Guide | For |
|---|---|
| [Send_Your_Link_iPhone.md](Send_Your_Link_iPhone.md) | iPhone |
| [Send_Your_Link_Android.md](Send_Your_Link_Android.md) | Pixel and other stock-Android phones |
| [Send_Your_Link_Samsung.md](Send_Your_Link_Samsung.md) | Samsung Galaxy |

All three cover the same two setups from `Spec A-13`: a **keyboard shortcut** that types
the intake link for you, and a **canned reply** you can send from an incoming call without
answering it. The link they hand out is the location's `go.rvintake.com` short link, which
is what records where each request came from.

> **Status: draft.** Every menu path below was written from the current published
> documentation for each platform and has **not yet been walked on real hardware**. Do that
> before any of this goes to a customer — the checklist at the end of each guide says
> exactly what to confirm. Phone-maker menus move between OS versions, and a guide that
> sends a service advisor to a menu that no longer exists is worse than no guide.
